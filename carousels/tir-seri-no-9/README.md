# TIR İşlemleri Seri No: 9 — carousel (11 sayfa, 1080×1350)

Gümrük Genel Tebliği (TIR İşlemleri) (Seri No: 1)'nde Değişiklik Yapılmasına Dair Tebliğ (Seri No: 9) ·
Resmî Gazete 4 Temmuz 2026, Sayı 33300. Sayfa sayfa içerik: [`ozet.md`](ozet.md).

**Tema — "Otoyol tabelası + clean sheet":** açık kareli not kâğıdı zemin, TIR plakası mavisi, mavi otoyol tabelası başlık;
altta asfalt şerit ve her sayfada biraz daha ilerleyen TIR kamyonu (ilerleme göstergesi).
Teknikler: zihin haritası (s.2), önce/sonra kartları (s.3, 4, 8), akış şeması (s.3, 4), yol/idare şeması (s.5),
iki karne zaman çizelgesi + 8 + 7 = 15 (s.6), konteyner dizisi çizimi + A/B karşılaştırma tablosu (s.7),
ek dosya sekmeleri ve zaman çizelgesi (s.9), tek sayfa clean sheet tablo (s.10), doğru/yanlış testi (s.11).
Rozetler: ÖNEMLİ · DİKKAT · TUZAK · YENİ · ESKİ · DEĞİŞMEDİ.
